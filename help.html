Frequently Asked Questions

What is Special Space?

Special Space is a prototype website that helps families, caregivers, and people with special needs find community support, local events, and volunteers in one place.

Is my information shared with everyone?

In this prototype, your information is saved only in your browser using localStorage. That means other people will not see your data unless you build a backend later.

Why do my volunteers/events disappear on another computer?

Because localStorage is stored per browser and per device. If you open the site on a different browser or computer, it will have its own saved data.

How do I add myself as a volunteer?

Go to the Volunteers page, fill in your info, and press Add Me. Your name will show up in the list on that page.

How do I add an event?

Go to the Events page, add an event title and date, then press Add Event. It will show in the event list.

How do I fix it if something looks broken?

Try refreshing the page. If you changed code, make sure the file name matches the link in the navigation. If you deployed on GitHub Pages, confirm you pushed the newest version.

Prototype note: This site is currently front-end only. If you want a real shared system, you’ll need a backend (Firebase, Supabase, or a simple Node server).
